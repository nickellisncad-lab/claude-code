# Flip Clock

A dependency-free split-flap flip clock, built with plain HTML, CSS, and JavaScript.

## Features

- Realistic flip animation for hours, minutes, and seconds
- Dark / light theme toggle (persisted with `localStorage`)
- Current date display
- Fully responsive, no build step or external dependencies

## Usage

Open `index.html` directly in a browser, or serve the folder locally:

```sh
cd flip-clock
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
